# تطبيق Mahdi Belaifa — نسخة Expo

تطبيق إدارة الطلبات مبني بـ Expo SDK 58 + Expo Router (Native Tabs):
الشريط السفلي هو شريط iOS الأصلي نفسه (Liquid Glass الحقيقي على iOS 26).

## الشاشات
- الرئيسية: إحصائيات + مداخيل + أحدث الطلبات
- الطلبات: فلترة حسب الحالة + قائمة
- تفاصيل الطلب: اتصال/واتساب + تغيير الحالة (زر التالي + كل الحالات)
- المنتجات + تفاصيل المنتج (الخيارات والصور)
- العملاء + تفاصيل العميل وطلباته
- المزيد: روابط اللوحة وصفحة الهبوط

## خطوات بناء الـ IPA (مرة واحدة)
1. أنشئ حسابا مجانيا في https://expo.dev
2. من موقع Expo: مشروعك ← Credentials ← iOS: ارفع ملف الشهادة (.p12) وملف
   التوفير (.mobileprovision) بنفسك — لا يمران عليّ أبدا.
3. أخبر المساعد أن الحساب والشهادة جاهزان، وهو يطلق البناء السحابي:
   eas build -p ios --profile preview
4. عند انتهاء البناء: حمّل الـ IPA الموقعة من Expo وثبّتها على هاتفك.

## التطوير المحلي
- npx tsc --noEmit  (فحص الأنواع)
- npx expo export --platform ios  (فحص الحزمة)
